# ROC ATC Special Exam 考古題

中華民國（台灣）航空管制相關國家考試歷屆試題 PDF，來源為[考選部考畢試題查詢平臺](https://wwwq.moex.gov.tw/exam/wFrmExamQandASearch.aspx)。

檔名格式：`民國年-科目_類別.pdf`，類別「特」＝民航特考三等，「薦」＝薦任升官等。例如 `113-航空氣象_特.pdf`。

- 097 年民航特考未設飛航管制科別。
- 098 年考選部網站僅提供專業科目（航空氣象、飛行原理）。
- 「英語會話」為口試，無書面試題。
